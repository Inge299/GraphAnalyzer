# SDK провайдеров данных

Провайдер данных является исполняемым Python-модулем, который выдаёт список ресурсов и получает данные для аналитических плагинов. Он не хранит секреты в метаданных.

## Контракт

Наследуйте `app.data_provider_sdk.DataProvider` и опишите `DataProviderManifest` с устойчивым `id`, названием, типом и возможностями. Реализуйте `list_resources(db)` и, при необходимости, `execute(db, resource_id, params)`.

Внешние `.py`-модули размещаются в `/app/data/data_providers`. При старте Nodex они автоматически обнаруживаются, проходят валидацию SDK и добавляют свои метаданные в `reference_providers.json`. Эти метаданные включаются в экспортный пакет.

## Встроенный MSSQL-провайдер

`console_mssql` использует исключительно активные источники и профили процедур из раздела «Консоль / процедуры». Он не выполняет произвольный SQL: ресурсом является заранее зарегистрированная процедура, а её параметры и таймауты остаются под контролем каталога процедур.

Аналитический плагин должен обращаться к провайдеру по `id`, выбрать ресурс и преобразовать ответ в факты, сущности и связи универсального хранилища проекта.
